# Bản thử roadmap KHMT

Theo thiết kế đã chốt trong chat: một chuỗi nhiệm vụ dọc; nhấp mở chi tiết gồm tên, việc cần làm, ghi chú/nguồn khi cần. React + React Flow, website tĩnh tương thích GitHub Pages. Bản thử giới hạn C++ cơ sở, OOP, Git và project thư viện; không tuyên bố là toàn bộ chương trình KHMT.

Giao diện: mục lục trái, canvas giữa, chi tiết phải. Màn hình nhỏ mở chi tiết bằng hộp thoại. Trạng thái chưa học/đang học/hoàn thành lưu trong trình duyệt, xuất/nhập JSON có kiểm tra dữ liệu. Không có đồng bộ máy chủ. Mỗi nhiệm vụ có ID ổn định để bổ sung chương trình mà không mất tiến độ.

Triển khai: soạn chương trình mẫu; dựng chuỗi thẳng và điều hướng; thêm lưu/sao lưu; kiểm thử logic nhập, build; kiểm tra tương tác thực tế bằng trình duyệt. Không cần tài khoản cho bản thử. Có cấu hình GitHub Actions để xuất bản sau khi có repository đích.
